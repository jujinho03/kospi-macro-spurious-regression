# KOSPI 금융 시계열 분석 포트폴리오 설명

## 프로젝트명

KOSPI 거시경제 변수 분석 — 정상성 진단과 허위회귀 검증

## 한 줄 소개

2010~2024년 월별 금융 시계열을 대상으로 수준 OLS의 높은 R²에 숨은 허위회귀 위험을 진단하고, 1차 차분·공적분 검정·HAC 강건 추론·시계열 홀드아웃으로 해석을 재검증한 프로젝트입니다.

## 문제와 접근

추세를 가진 금융 시계열의 수준값을 그대로 회귀하면 높은 설명력이 나타나도 허위회귀일 수 있습니다. 따라서 정상성과 공적분, 잔차 자기상관·이분산성을 먼저 점검하고 1차 차분과 HAC 강건 표준오차로 해석을 교정했습니다. 무작위 분할 대신 마지막 24개월을 홀드아웃으로 두어 시간 순서를 보존했습니다.

## 수행 내용

- KOSPI·S&P 500·원/달러 환율·WTI 수집과 ECOS 국고채 3년 금리 파싱
- 일별 시장 데이터의 월말 집계와 재구축 전·후 68개 변경값 감사
- ADF·KPSS·ACF를 활용한 수준·1차 차분 정상성 진단
- 수준 OLS·Engle–Granger 공적분·잔차·VIF 진단
- 1차 차분 OLS와 HAC(Newey–West) 강건 표준오차 추론
- 24개월 시계열 홀드아웃, 수준 경로 복원과 표준화 잔차 이상 시점 탐지

## 핵심 결과

- 수준 OLS R² 0.8103이지만 Durbin–Watson 0.2611, 공적분 p-value 0.5901로 허위회귀 위험 확인
- 1차 차분 후 Durbin–Watson 2.0102, Ljung–Box p-value 0.8599로 잔차 자기상관 완화
- HAC 기준 환율 변화(−), S&P 500 변화(+), WTI 변화(+)가 5% 수준에서 유의
- 금리 변화는 일반 OLS와 달리 HAC 적용 후 5% 수준에서 유의하지 않음
- 차분 모형 홀드아웃 RMSE 98.0467, 방향 정확도 66.67%
- 차분 수준 복원은 수준 OLS 대비 RMSE 12.4% 개선, 다만 두 모형 모두 수준 경로 R² < 0

- 정상성·허위회귀·잔차 구조를 확인한 강건 통계추론
- 시간 순서 기반 홀드아웃과 결과 해석의 한계 점검
- 재현 가능한 노트북, 결과표와 분석 보고서 작성

## 설명 가능한 범위

이 프로젝트는 학부 수준에서 금융 시계열의 검증 절차와 선형모형 해석을 다룬 결과입니다. 높은 적합도를 바로 경제적 관계나 예측력으로 해석하지 않습니다. 통계적 유의성은 정상성·잔차 구조·강건 표준오차를 확인한 뒤 판단하고, 24개월 홀드아웃의 66.67% 방향 정확도는 표본 제약을 고려해 보조 지표로만 제시합니다. 모든 계수는 동시점 연관성이며 인과효과를 의미하지 않습니다.
