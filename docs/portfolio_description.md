# Portfolio Description

## 프로젝트명

KOSPI 거시경제 변수 분석: 정상성 진단과 허위회귀 검증

## 한 줄 요약

2010~2024년 월별 금융 시계열을 활용해 KOSPI와 환율·금리·S&P 500·WTI의 관계를 분석하고, 정상성 검정·공적분 검정·잔차 진단·HAC 추론·시계열 홀드아웃 평가를 통해 수준 회귀의 허위회귀 위험을 검증한 금융 시계열 분석 프로젝트입니다.

---

## 프로젝트 배경

금융 시계열의 수준값은 장기 추세를 공유하는 경우가 많아, 단순 OLS 회귀에서 높은 결정계수와 유의한 회귀계수가 나타나더라도 실제 경제적 관계가 아닐 수 있습니다.

본 프로젝트에서는 수준 회귀의 결과를 그대로 해석하지 않고 다음 절차를 통해 분석의 통계적 타당성을 검토했습니다.

1. 수준 변수의 정상성 진단
2. 수준 OLS의 잔차 자기상관 및 이분산성 검정
3. Engle–Granger 공적분 검정
4. 1차 차분을 통한 정상성 확보
5. 차분 OLS의 잔차 진단
6. HAC 강건 표준오차를 통한 계수 추론
7. 시계열 홀드아웃 평가
8. 차분 예측값의 KOSPI 수준 경로 복원
9. 표준화 잔차 기반 이상 시점 탐지

## 핵심 수행 내용

### 데이터 수집 및 정제

* KOSPI, S&P 500, 원/달러 환율, WTI 자동 수집
* 한국은행 ECOS 국고채 3년 금리 CSV 파싱
* 일별 시장 데이터의 월말 종가 변환
* 월별 날짜 인덱스 정합성 검증
* 최종 결측치 0개 확보
* 재구축 전후 데이터 변경 이력 저장

재구축 이전 데이터와 비교한 결과 환율 42개월, WTI 26개월 등 총 68개 값의 변경 내역을 확인하고 별도 CSV로 보존했습니다.

### 정상성 및 허위회귀 진단

* ADF 검정
* KPSS 검정
* 수준 및 차분 시계열 ACF 분석
* 수준 OLS와 1차 차분 OLS 비교
* Engle–Granger 공적분 검정

KOSPI, S&P 500, 환율 및 금리의 수준값은 비정상 시계열로 판정되었습니다. 모든 변수는 1차 차분 후 정상성을 확보했습니다.

### 회귀모형 검증

* Durbin–Watson 검정
* Ljung–Box 검정
* Breusch–Pagan 검정
* Jarque–Bera 검정
* VIF 진단
* HAC(Newey–West) 강건 표준오차 적용

### 예측 및 이상 시점 평가

* 시계열 순서를 보존한 최근 24개월 홀드아웃
* 수준 OLS 예측
* 차분 OLS 변화량 예측
* 방향 정확도 평가
* 차분 예측값의 KOSPI 수준 경로 복원
* 표준화 잔차 기반 이상 시점 탐지

## 핵심 분석 결과

### 수준 OLS

| 지표                    |         결과 |
| --------------------- | ---------: |
| 학습 R²                 |   0.810265 |
| Durbin–Watson         |   0.261111 |
| Ljung–Box p-value     | < 0.000001 |
| Breusch–Pagan p-value |   0.000001 |
| 공적분 검정 p-value        |   0.590111 |

수준 OLS는 높은 설명력을 보였지만 다음 문제가 확인되었습니다.

* 비정상 수준 변수
* 강한 잔차 자기상관
* 이분산성
* 공적분 근거 부재
* 특정 기간에 집중된 잔차 군집

따라서 수준 OLS는 장기 관계를 설명하는 최종 모형이 아니라 허위회귀 위험을 보여주는 비교·진단 모형으로 사용했습니다.

### 1차 차분 OLS

| 지표                    |       결과 |
| --------------------- | -------: |
| 학습 R²                 | 0.561996 |
| Durbin–Watson         | 2.010219 |
| Ljung–Box p-value     | 0.859924 |
| Breusch–Pagan p-value | 0.009529 |
| Jarque–Bera p-value   | 0.000006 |

1차 차분 후 잔차 자기상관은 해소되었지만 이분산성과 비정규성이 남아 있어 HAC 표준오차를 사용했습니다.

### HAC 추론

| 변수         | 계수 방향 |    p-value | 판단              |
| ---------- | ----- | ---------: | --------------- |
| 원/달러 환율 변화 | 음의 관계 |   0.009472 | 유의              |
| 금리 변화      | 음의 방향 |   0.070881 | 5% 수준에서 유의하지 않음 |
| S&P 500 변화 | 양의 관계 | < 0.000001 | 유의              |
| WTI 변화     | 양의 관계 |   0.000069 | 유의              |

일반 OLS에서는 금리 변화가 유의했지만 HAC 적용 후에는 유의하지 않았습니다. 이를 통해 강건 표준오차 적용 여부가 변수 유의성 판단에 영향을 줄 수 있음을 확인했습니다.

## 홀드아웃 결과

### 월간 KOSPI 변화량

| 지표     |        결과 |
| ------ | --------: |
| MAE    | 75.176237 |
| RMSE   | 98.046746 |
| R²     |  0.230724 |
| 방향 정확도 |    66.67% |

### KOSPI 수준 경로 비교

| 모형           |        MAE |       RMSE |        R² |
| ------------ | ---------: | ---------: | --------: |
| 수준 OLS       | 239.032400 | 289.290943 | -4.367919 |
| 차분 OLS 수준 복원 | 180.788683 | 253.408947 | -3.118890 |

차분 복원 모형은 수준 OLS보다 MAE와 RMSE가 개선되었지만, 두 모형 모두 수준 경로 기준 R²가 0보다 작았습니다.

따라서 본 프로젝트의 핵심 성과는 높은 예측 정확도가 아니라 금융 시계열 분석에서 정상성, 잔차 구조, 강건 추론 및 평가 척도의 중요성을 검증한 데 있습니다.

## 이상 시점 탐지

표준화 잔차의 절댓값이 2 이상인 관측치를 이상 시점으로 정의했습니다.

* 수준 OLS: 8개
* 1차 차분 OLS: 8개

수준 OLS의 이상 잔차는 주로 2021년에 연속적으로 집중되었습니다. 이는 개별 시장 충격보다 모형의 지속적인 과소예측 및 자기상관과 관련된 패턴입니다.

차분 OLS의 이상 잔차는 여러 시점에 산발적으로 나타났으며, 급격한 시장 변동과 두꺼운 꼬리의 영향을 시사합니다.

## 직무 연관성

### 금융 데이터 분석

거시·금융 변수의 월별 시계열 구조를 분석하고, 통계적 관계와 예측 한계를 함께 제시했습니다.

### 리스크 및 모델 검증

높은 R²를 그대로 수용하지 않고 정상성, 공적분, 잔차 자기상관, 이분산성 및 강건 표준오차를 단계적으로 검증했습니다.

### 데이터 품질 관리

재구축 이전 데이터와 신규 데이터를 비교해 변경된 68개 값을 추적 가능한 형태로 저장했습니다.

### 예측모형 평가

시계열 순서를 보존한 홀드아웃 평가를 적용하고, 서로 다른 단위의 예측값을 직접 비교하지 않도록 차분 예측값을 KOSPI 수준으로 복원했습니다.

### 결과 커뮤니케이션

예측 성능의 한계를 숨기지 않고, 모형의 유효 범위와 통계적 해석상의 제한을 명확히 기술했습니다.

## 프로젝트의 차별점

일반적인 회귀분석 프로젝트는 높은 결정계수와 유의한 변수에 초점을 맞추는 경우가 많습니다.

본 프로젝트는 오히려 높은 수준 OLS의 설명력이 왜 위험할 수 있는지를 진단하고, 다음 과정을 통해 분석을 재설계했습니다.

* 비정상성 확인
* 허위회귀 위험 검토
* 공적분 부재 확인
* 1차 차분 적용
* 잔차 자기상관 개선
* HAC 강건 추론
* 동일한 척도의 예측 성능 비교
* 이상 잔차 패턴 분석

이를 통해 금융 시계열 모델에서 단순 적합도보다 분석 타당성과 검증 절차가 중요하다는 점을 보여주었습니다.
