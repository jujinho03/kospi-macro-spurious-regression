# 원본 데이터 준비

이 폴더에는 프로젝트를 처음부터 재현할 때 필요한 한국은행 금리 원본을 보관합니다.

1. 한국은행 경제통계시스템(ECOS)에서 `시장금리(월, 분기, 년) > 국고채(3년)`을 선택합니다.
2. 기간을 2010.01~2024.12, 주기를 월로 설정해 CSV를 내려받습니다.
3. 원본 구조를 수정하지 않고 다음 경로에 배치합니다.

```text
data/raw/interest_rate.csv
```

해당 파일은 연 % 단위의 월별 국고채 3년 금리 180개월을 포함합니다. 모든 파싱·날짜 변환·결측 검사는 `notebooks/01_data_collection_cleaning.ipynb`에서 수행합니다.

KOSPI, S&P 500, 원/달러 환율, WTI는 같은 노트북이 `yfinance`를 통해 실행 시점에 수집합니다. 데이터 공급자의 과거값 수정에 따라 일부 값이 달라질 수 있어, 최종 처리 데이터와 재구축 전·후 비교 결과를 함께 보존합니다.

PowerShell에서 다음 명령을 실행하면 금리 파일의 배치 여부를 확인할 수 있습니다.

```powershell
Test-Path .\data\raw\interest_rate.csv
```

`True`면 로컬 원본 데이터 준비가 완료된 것입니다. 외부 시장 데이터 수집을 위해 첫 번째 노트북 실행 시 인터넷 연결이 필요합니다.
