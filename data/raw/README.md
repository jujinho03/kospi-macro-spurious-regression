# Raw Data

이 폴더에는 프로젝트를 처음부터 재현하기 위해 필요한 원천 데이터를 저장한다.

## 1. 파일 목록

### `interest_rate.csv`

한국은행 경제통계시스템(ECOS)에서 내려받은 월별 국고채 3년 금리 원본 CSV 파일이다.

* 통계표: 시장금리(월, 분기, 년)
* 계정항목: 국고채(3년)
* 주기: 월
* 기간: 2010.01 ~ 2024.12
* 단위: 연 %
* 관측치: 180개월
* 수집일: 2026-06-27
* 출처: 한국은행 경제통계시스템(ECOS)

원본 데이터의 구조와 값을 임의로 수정하지 않고, 데이터 수집·정제 노트북에서 파싱하여 사용한다.

## 2. 자동 수집 데이터

다음 금융시장 변수는 `yfinance`를 통해 노트북 실행 시 수집한다.

* KOSPI 지수
* S&P 500 지수
* 원/달러 환율
* WTI 원유 가격

자동 수집 데이터는 실행 시점과 데이터 공급자의 수정 정책에 따라 일부 값이 달라질 수 있으므로, 최종 분석에 사용된 처리 데이터와 데이터 품질 점검 결과를 함께 저장한다.

## 3. 데이터 사용 원칙

* 원천 파일은 직접 수정하지 않는다.
* 모든 정제와 변환은 노트북 코드로 수행한다.
* 날짜 범위, 중복값, 결측치 및 비수치 값을 점검한다.
* 전처리된 데이터는 `data/processed/`에 별도로 저장한다.
* 분석 결과는 원천 데이터가 아닌 재현 가능한 코드 실행을 통해 생성한다.
